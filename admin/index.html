Configurar el panel

Se hace una sola vez. Después se entra solo con usuario y contraseña.

  1. Creá un token de GitHub con permiso para modificar el repositorio carloscutini.github.io (token fine-grained: solo ese repositorio, permiso Contents: Read and write).
  2. Pegalo acá y elegí el usuario y la contraseña para entrar.

El token queda guardado en la web cifrado con esta contraseña: cuanto más larga, más seguro.
